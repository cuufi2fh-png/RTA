# RTA 기획 포트폴리오

RTA는 ALPHA Studio에서 공동 제작 중인 Roblox 도시 생활·역할수행 게임입니다. 제작 기간은 3개월, 팀 규모는 18명입니다. 이 저장소는 기획 참여와 공동 프로젝트 자료를 구분하여 정리한 참고 자료입니다.

## 담당과 코드 출처

지원자의 담당은 **기획**이며 **직접 작성한 코드는 없습니다**. 이 저장소의 구현 코드는 지원자의 직접 작성 코드 증빙이 아닙니다. 개발 기록에는 Codex를 통한 AI 코드 생성·수정이 포함되어 있습니다. 팀원별 코드 기여도는 확정하지 않았습니다.

학교 안내에는 AI 작성 코드를 허용하지 않고 지원자가 직접 작성한 코드를 요구한다고 명시되어 있습니다. 기획 담당 공동 작품의 인정 여부는 학교 확인이 필요하며, 저장소를 만들었다는 사실이 해당 요건 충족을 뜻하지 않습니다.

## 기획 기여

- 지도 배치도와 시설 용도 지정: 주거·사업 구역을 빈 플롯으로 구성하고 중앙에 대형 주거 부지 배치.
- 헬리콥터 표시를 헬기 딜러샵으로 구분.
- 건물 외관과 내부 시안 검토 절차 요청.
- 낚싯대로 직접 잡는 낚시 경험과 FISHING 판매점의 역할 명확화.
- 도시 도우미 UI 제거 요청.
- 경찰서 본관·별관을 언덕 위에 배치하도록 결정.

## 구성

- `source/`: 업로드한 RTA.rbxl에서 추출한 Luau 소스 621개와 index.json. 파일명 앞 숫자는 추출 식별자이며, 인스턴스 이름·종류는 index.json에 있습니다.
- `build/RTA.rbxl`: 사용자가 저장한 전체 Roblox 장소 파일. Roblox Studio에서 직접 열 수 있습니다.
- `BUILD.md`: Roblox Studio에서 설치하는 방법과 제약.
- `PROVENANCE.md`: AI 및 외부 자료 출처 구분.

## 현재 상태

개발 중인 공동 프로젝트입니다. 저장된 작업 기록에는 두 경찰서 출입과 진입로 보행 검사가 보고되어 있습니다. 이번 저장소 구성 작업에서는 게임 실행·실서버·모바일·실결제 검증을 새로 수행하지 않았습니다. YouTube 플레이 영상은 아직 없습니다.

개인 성명·학교가 들어간 입시 서류는 이 저장소에 포함하지 않았습니다. 사용자의 요청에 따라 공개 저장소로 전환합니다.
